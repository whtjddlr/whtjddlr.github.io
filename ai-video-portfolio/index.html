02 / MotionFlow

영상 제작 워크플로우를 만든 이유

MotionFlow는 장면 기획부터 이미지 생성, 영상 제작까지 이어주는 AI 영상 제작 워크플로우입니다. 프롬프트 작성과 생성 단계가 서로 끊겨 같은 장면 정보를 매번 다시 입력해야 하는 문제를 줄이기 위해 만들었습니다.

01 / 기획 배경 분산된 작업 프롬프트를 매번 새로 쓰고, 이미지와 영상 도구 사이에서 같은 인물·장면·구도 정보를 반복해서 옮기는 일이 번거롭고 어려웠습니다.
02 / 만든 방식 정보 연결 장면 설정과 프롬프트를 기준 이미지에 연결하고, 선택한 이미지를 영상 제작 입력으로 넘겨 한 화면에서 흐름을 이어가도록 구성했습니다.
03 / 얻은 인사이트 맥락 유지 프롬프트를 따로 잘 쓰는 것보다 장면 기준과 선택 결과가 다음 생성에 그대로 이어질 때 반복 작업과 수정 비용이 줄었습니다.

03 / MotionFlow

한 장면이 영상이 되는 과정

한 번 정한 장면 정보를 이미지와 영상 제작에 이어 쓰고, 앞 장면을 수정하면 다시 확인해야 할 뒤 장면까지 보여주는 흐름입니다.

01 / 장면 연결앞뒤 장면 분석

인물·장소·소품이 이어지는 장면을 확인합니다.

장면 목록 → 연결 관계
→
02 / 기준 작성장면 기준 작성

인물, 구도, 조명, 동작을 한 번 입력해 장면 기준으로 정리합니다.

연출 의도 → 장면 기준
→
03 / 이미지4개 구도 비교

같은 기준으로 와이드·미디엄·클로즈업·대체 구도를 만듭니다.

장면 기준 → 선택 이미지
→
04 / 영상움직임 적용

선택 이미지와 모델별 움직임 지시문으로 영상을 제작합니다.

선택 이미지 → 영상 후보
→
05 / 수정 확인후속 장면 영향

앞 장면의 변경이 영향을 주는 뒤 장면만 다시 확인합니다.

변경 내용 → 확인할 장면

04 / PlanMerge

PlanMerge기획안 통합 도구

PlanMerge는 영상 제작 전에 여러 관점에서 만든 기획안을 비교하고 하나로 정리하는 별도의 기획 도구입니다. 어떤 제안이 선택되거나 제외됐는지 확인할 수 있으며, MotionFlow와 달리 제작 전 기획을 비교하고 결정하는 과정을 다룹니다.
